# Sidecar、Hub 与 NetIO

> 状态：active ｜ 最后更新：2026-11-24 ｜ 负责人：AndX 维护者

非 IODevice、多 Host 或独立升级可评估 Sidecar，多屏可评估 Hub＋NetIO。本技能提供选型检查，没有通用部署包或现场验收承诺。

1. 读取实际服务/插件版本、监听地址、健康检查和服务管理，确认能力存在。Sidecar 不拥有物理设备。
2. Cloud/BFF 负责租户与业务授权，Hub 路由授权展项；NetIO 仅作局域网承载，不读取 NodeSecret 或承担公网会话。
3. 每个设备单 Host 所有，区分控制/显示节点、状态来源与恢复策略；在线不等于可执行。
4. 验断网、节点离线、Hub 退出、重复/过期/乱序消息与操作员撤销后的安全状态，本地停止不能依赖云端。
5. 媒体用受控引用/内容通道，验证来源、路径、大小、类型、哈希与配额，不放进控制 RPC。
6. 环回与 LAN 暴露分别检查鉴权、来源与网络限制；浏览器另验安全上下文/混合内容/origin，环回通过不代表 LAN 通过。

真实验收使用本次涉及的进程/节点数量，证明路由、状态归属、恢复无误动作，以及请求的控制或媒体链路。无多节点环境时分别记录模拟与现场待验。
