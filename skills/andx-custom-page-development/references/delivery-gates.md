# 交付门禁

| 门禁 | 必须通过 |
|---|---|
| 规格 | page key、版本、展示模式、Bridge 能力和验收标准明确 |
| 静态契约 | 入口、文件类型、路径、大小、相对资源和 MyriadBox 边界 |
| Bridge | 握手、能力、状态、支付成功/取消、事件、撤销、Console |
| 候选包 | 确定性 ZIP、manifest、SHA-256 |
| 预览部署 | 工程绑定、凭证 Broker、查重、上传、健康检查、幂等回执 |
| 真实页面 | 候选隔离预览截图、Console、Network、Bridge 与 SHA；激活后再检查固定 `/x/` |
| 人工审批 | 用户明确批准版本和 SHA |
| 激活 | 预期 SHA、预览时 activation 修订、精确发布回执、回滚目标 |
| 二维码 | 固定 `/x/{publicCode}`，可供微信扫码 |
| 最终验收 | 小程序 web-view 与微信浏览器双入口人工确认 |
